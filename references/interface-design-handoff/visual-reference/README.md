This folder is a static copy of the Ovanova design system, with every token, the type scale and 43 components laid out and labelled.
It was built from tree b44c0be3 (the merged fifteen open pull requests plus the two equipment tests) on 2 October 2026.
To open it, double click index.html. Every link is relative, no server and no network are needed, and bundle/ holds the files the previews run from.
Components marked floor card have no written preview yet and show a placeholder.
For any component already in the repo, the repo is the source and this export is a snapshot, so check the file under app/components before copying anything from here.
