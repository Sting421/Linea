CustomSwitch from reap. Use via `window.Reap.CustomSwitch` (bundle loaded from the root `_ds_bundle.js`).

## Examples

### Default

```jsx
() => (
  <div style={{ display: 'flex', alignItems: 'center', gap: 12 }}>
    <CustomSwitch />
    <span style={{ fontSize: 14, color: '#444343' }}>Toggle setting</span>
  </div>
)
```
