Scope note. Severity (Normal/Warning/Offline/Fault, plus the derived Anomaly) is distinct from lifecycle state (New / Ack'd / Resolved / Auto-recovered), the gray state pill above is a separate concern handled by the incident lifecycle controls. Color reservation: the five status hues (incl. violet = Anomaly) carry status meaning only; decorative and UI accents draw from the non-status accent set (navy, teal, orange, rust, green), and charts that split a value into categories use the dedicated categorical palette (--cat-*: solar, battery/SOC, grid import/export, home load, generator, self-consumption, curtailed). Next foundations: chart primitives and the shared map, which the rest of Areas 1–3 depend on.
