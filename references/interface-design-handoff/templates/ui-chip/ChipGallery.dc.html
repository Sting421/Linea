Three families. Neutral for plain facts. Status hues (sky / green / amber / red) mirror SeverityBadge, so reserve them for genuine status. The Area 2 working-mode palette colors each mode by identity (Self-Consumption sky, Backup green, Time-of-Use orange, Peak teal, AC Charge rust); teal / orange / rust are unique to modes, and the mode set only appears on Control surfaces, so it never collides with status.
