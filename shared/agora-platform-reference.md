# Agora platform reference for both products

As of 26 September 2026, from Agora's public documentation. Where the
API reference page and the release notes disagree on supported vendors,
the release notes are newer. Items marked **verify** must be confirmed
in the Console or by a test call.

## 1. The engine in one paragraph

Agora's Conversational AI Engine is started by a REST call. Our server
posts a configuration to `join`, and an AI agent joins an RTC channel as
a participant. In cascading mode the engine runs speech recognition,
calls a language model (ours, through a custom endpoint), and speaks the
reply through a TTS vendor. The engine handles voice activity detection,
interruptions and turn taking. We control the agent during the session
with the `think`, `speak`, `interrupt` and `leave` endpoints, and we
read what happened through history and webhooks.

## 2. Authentication

All REST calls use HTTP Basic Auth with the Customer ID and Customer
Secret from the Agora Console, base64 encoded as
`customer_id:customer_secret`. The App ID is in the path. Tokens for the
channel are generated by our server with the App Certificate, and must
carry RTC privileges, plus RTM privileges when `enable_rtm` is true.

Limits: one App ID allows 20 peak concurrent users calling the server
API by default, and no session runs longer than 72 hours.

history and metrics.

## 5. Telephony

Outbound, confirmed on 2 October:
`POST https://api.agora.io/api/conversational-ai-agent/v2/projects/{appid}/call`
with `name`, `sip.to_number` and `sip.from_number` in E.164,
`sip.rtc_uid` and `sip.rtc_token` for the SIP gateway, and either
`pipeline_id` (a published Console agent) with a minimal `properties` of
`channel`, `token`, `agent_rtc_uid`, `remote_rtc_uids`, or the complete
`properties` object from `join`. On telephony calls `remote_rtc_uids`
supports exactly one uid, which must be the gateway's `rtc_uid`, so the
agent hears only the phone line. A browser that joins the channel is
still heard on the phone, because the gateway carries the channel mix
(confirmed in test B3). The response is `agent_id`. A 400
`invalid_phone_format` means the number is not E.164. A `TaskConflict`
with an `agent_id` means a session with that `name` is already running,
and the returned id is the live one.

Inbound: import the number in the Console's Phone Numbers page, copy the
Origination URI back to the trunk, assign the number to an agent, set
max call duration and silence timeout. Not needed for Linea's MVP.

Console tools, confirmed: the Console at console.agora.io has Agents (a
builder with Prompt, Models, Advanced, Actions, a Test call, a Code tab
with the REST body, and a Deploy tab), Phone Numbers (Add Phone Number
with SIP trunk address, transport, username and password), and Outbound
Campaigns (a CSV of `phone_number` rows that places calls, with max call
seconds, transcript and recording toggles). A one row campaign is a
quick way to place a test call without code.

SIP trunk setup, confirmed: Twilio Elastic SIP Trunking with a
Termination URI (`linea-keias.pstn.twilio.com`) and a Credential List
for authentication worked without adding Agora's SIP IPs to an IP Access
Control List, because Agora's Add Phone Number form sends the username
and password. Transport TCP on port 5060. Philippines must be enabled
under Twilio Voice Geo Permissions. Twilio SIP trunking to Philippine
numbers costs \$0.203 to \$0.290 per minute. Telephony is free on
Agora's side during beta.

Philippine specifics, confirmed: Twilio's Philippine local numbers need
a local address and documents, toll free ones cost \$25 a month, and
mobile numbers are SMS only. A US local number at \$1.15 a month calls
the Philippines fine. Caller ID shows the US number, which is why Linea
has the family record an intro and save the number on the elder's phone.

## 6. Client side

-   Web: `agora-rtc-sdk-ng` for audio and video, `agora-rtm` for
    signaling when `enable_rtm` is true. Agora's conversational AI
    client toolkit for Web, iOS and Android adds transcripts, agent
    state events and manual turn control.
-   The family or therapist joins the same channel as a normal RTC user
    with a token from our server.
-   Manual turn control (push to talk) is signaled over RTM. Not needed
    for Linea or Kasangga MVP.

## 7. Custom LLM contract

The engine posts to `llm.url` with an OpenAI chat completions request.
With `vendor: custom`, each request also carries `turn_id` and
`timestamp`. We should respond with a streaming or non streaming chat
completion. Tool calls can be handled in two ways: by returning OpenAI
tool calls that our own endpoint executes before answering (simplest,
everything stays in our server), or by declaring Agora custom HTTPS
tools. For 12 hours, execute tools inside our endpoint and return plain
text. Keep replies short, since every token is spoken.

## 8. Languages and voices

-   ARES speech recognition supports `en-PH`, `fil-PH` and `tl-PH`.
    Cebuano, Hiligaynon and Waray are not listed.
-   Semantic end of speech is English and Chinese only. Filipino uses
    silence based turn detection, so tune `silence_duration_ms`.
-   Google Cloud Speech-to-Text v2 lists Cebuano `ceb-PH` on the
    `chirp_2` model. Whether Agora's Google ASR option accepts that code
    is test T3.
-   Microsoft Azure Speech has Filipino neural voices and is in Agora's
    base TTS list, which makes it the lowest risk TTS for Filipino.
    Google Cloud TTS also has Filipino voices in Standard, WaveNet and
    Neural2 tiers. ElevenLabs multilingual covers Tagalog. Pick by
    listening.

## 9. Costs

-   Conversational AI Engine from \$0.10 per minute after the first 300
    free minutes.
-   Voice calling has 10,000 free minutes per month per project.
-   Telephony is free on Agora's side during beta. Twilio charges per
    minute for the trunk and for international termination to the
    Philippines.
-   TTS and ASR vendors charge separately unless Agora's managed mode is
    used for that vendor.
